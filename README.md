# Dino Run

A dinosaur runner for a round screen: jump over cacti, duck under birds, 10 levels.

**Play:** https://oorhuri.github.io/dino-run/

- **Solo** — clear a set number of obstacles to pass each level.
- **Online with a friend** — one player creates a room and shares the 4-letter code, the other joins. You run from opposite sides and meet in the middle. Uses PeerJS for a direct browser-to-browser connection; if it fails on mobile data, try Wi-Fi.

Controls: jump button / tap the screen / Space or ↑ — duck: ↓ button or key.
